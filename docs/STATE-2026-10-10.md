# State on 2026-10-10 (historical log; superseded)

Branch `integrate` = working fork state; nothing pushed except the `dxmt-e94c312` release asset.

## Works (verified on M5 Max, macOS 27.0.1, WineCX 11.15 + GPTK 4.0b2 D3DMetal)
- 14+ Windows-only games reach a full-screen window; Spider-Man 2 plays (77.9 fps, loads save). See compat/games.json.
- Retina: D3DMetal back buffers sized in pixels (winemac patch, 233353d).
- Xbox controllers: SDL-enabled winebus (9a0cbf5). Do NOT set winebus `Hidraw=1` for pads; it bypasses SDL.
- Controllers need no per-game Input Monitoring grant: the run script starts the launcher bundle directly instead of via `open`, so TCC attributes HID access to Steam (verified: all `kTCCServiceListenEvent` requests from Horizon `responsible=com.valvesoftware.steam`, authValue=2). `AMBAPLAY_LAUNCH_SERVICES=1` (or `NOTPROTON_LAUNCH_SERVICES=1`) restores the old `open` launch.
- Pads SDL doesn't know: `~/Library/Application Support/ambaplay/gamecontrollerdb.txt` is exported as `SDL_GAMECONTROLLERCONFIG`. GameSir G7 Pro dongle (3537:1022) mapping lives there; SDL IOKit axis order is X,Y,Z,Rz,Accel,Brake (browser Gamepad API numbers them differently). Never use the winebus registry `map` key: its loader (main.c:1101, writes `mappings[count]` after `count++`) crashes winebus and kills every pad.
- Bluetooth GameSir G7 Pro: its primary HID usage is Consumer, so stock SDL skips it; bundled libSDL2 carries winemac-patch/sdl2-iokit-gamepad-collection.patch, and the run script exports SDL_JOYSTICK_MFI=0 (SDL's MFi driver claims the pad but finds nothing in winedevice.exe). Verified 2026-10-11: winebus `sdl_add_device … is_gamepad 1`, user confirmed input in Megabonk.
- Many games need `ROSETTA_ADVERTISE_AVX=1` (set in user gamefixes/default.conf and per-game Steam launch options).

## Blockers / open
- Ambaplay can't deploy to Steam: App Management permission is lost on every ad-hoc rebuild (`run failed: cannot write /Applications/Steam.app/Contents/MacOS`). User must re-allow Ambaplay in Privacy & Security > App Management. Long-term: sign builds with a stable identity.
- Ravenswatch: fixed by winemac 76d8f938… (CW HACK 22435 in winecx-d3dmetal-retina.patch: queue D3DMetal client view frames before WM_SIZE so ResizeBuffers sees the borderless size; 3024x1964 confirmed by user via Metal HUD 2026-10-10).
- Borderlands 4: hangs before first frame (exception storm, likely Denuvo under Rosetta). Not solved.
- The Last of Us Part I: not crashing; probably long first shader build. Skipped by user.
- DOOM: The Dark Ages / Indiana Jones need hardware ray tracing (MoltenVK has none); Half-Life: Alyx is VR.
- Native macOS games (2026-10-11): stay native (no CompatToolMapping, no `userdata/*/config/compat.vdf` platform_overrides). Steam on macOS execs launch options literally, so `VAR=1 %command%` fails with OS Error 260; use `/usr/bin/arch -arm64 -x86_64 -e VAR=1 %command% <flags>` (also stops Rosetta inheritance from the x86_64 Steam client). Bluetooth GameSir G7 Pro in native Unity games: `native-shim/gamepad_shim.c` (DYLD_INSERT_LIBRARIES, built to `~/.ambaplay/libnp_gamepad.dylib`) presents it as an Xbox Wireless Controller and rewrites report 7 to the Xbox BT layout; verified in Chained Beasts Demo (arm64, controller works).
